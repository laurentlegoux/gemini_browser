# gemini_browser

A browser for the Gemini Protocol written in micropython with LVGL for MicropythonOS. A minimalistic gemini browser to access the geminispace.

## What is gemini protocol ?

[Gemini is a simple protocol](https://geminiprotocol.net/docs/) for serving content over the internet. It specifies a Markdown inspired format allowing basic plain text document markup. Compared to HTTP and HTML, Gemini is vastly simpler and easier to work with.

This application-layer internet communication protocol introduced in 2019 by pseudonymous developer Solderpunk is designed as a middle ground between the minimalism of Gopher and the complexity of HTTP.

As it is very lightweight and not verbose, it's a perfect fit for micropythonOS devices !

So i'm please to bring with love this browser to MicropythonOS and Gemini communities.

## What is micropythonOS ?

[MicroPythonOS](https://micropythonos.com/) is a lightweight, fast, and versatile operating system designed to run on microcontrollers like the ESP32 and desktop systems. With a modern Android-like touch screen UI, App Store, and Over-The-Air updates, it’s the perfect OS for innovators and developers.

## Install

The simplest way to install gemini_browser on your micropython is to install it through the MicropythonOS store app. You can also find the application bundle (mpk) in the [releases](https://github.com/laurentlegoux/gemini_browser/releases).
